OpenMat Documentation

The Official Language Specification and Roadmap

Welcome to OpenMat! OpenMat is a high-performance mathematical scripting language powered by a native Rust engine. It compiles directly into WebAssembly, allowing complex calculus and matrix algebra to run instantly in the browser.

1. Current Capabilities

The OpenMat language engine currently implements a robust Abstract Syntax Tree (AST) supporting variables, control flow, mathematical tensor operations, and an integrated reverse-mode Autograd system.

  • Native Tensor Math: Compute Element-wise mathematical operations natively across multi-dimensional arrays without loops.
  • Linear Algebra: Natively execute dot products, cross products, and matrix transformations instantly using BLAS-like efficiency.
  • Autograd: Train neural networks using native backwards propagation capabilities built into the runtime.
  • WebAssembly Core: The entire parser and evaluator runs at near-native speeds in any modern web browser.

2. Language Specification

Variables & Data Types

Variables are dynamically typed and initialized instantly.

// Floats and Strings
Scale = 10.5;
Message = "Initializing network...";

// 1D Tensors
Weights = [0.1, 0.5, -0.2];

// 2D Matrices
Image = [[255.0, 128.0], [0.0, 64.0]];

Matrix Mathematics

Standard operators (`+`, `-`, `*`, `/`) apply element-wise across arrays. The `@` operator computes the dot product or matrix multiplication.

A = [1.0, 2.0, 3.0];
B = [4.0, 5.0, 6.0];

// Element-wise addition
C = A + B; // [5.0, 7.0, 9.0]

// Dot Product
D = A @ B;

Built-in Standard Library

OpenMat provides native mathematical and algorithmic primitives:

// Array generation
X = linspace([-10.0, 10.0, 100]);

// Trigonometry
Y = sin(X) + cos(X);

// Activation Functions
Z = sigmoid(Y) + relu(Y);

// Array utilities
Length = len(X);
Total = sum(X);

3. Future Scope & Roadmap

OpenMat is an open-source project actively seeking contributions. Here is the roadmap for future capabilities:

Phase 1: File I/O & Persistence

We plan to implement `csvread()` and `csvwrite()` capabilities, allowing users to import massive real-world datasets into the OpenMat engine natively.

Phase 2: DataFrames

Implementing a `DataFrame` native struct with column indexing to handle labelled tabular data, similar to Pandas, but powered natively by the Rust backend.

Phase 3: 3D Visualization

Integrating WebGL or Three.js to provide native `surf()` and `mesh()` functions, rendering interactive 3D visualizations directly within the Web IDE Output Pane.
