Language Reference

Arrays & Matrices

Define arrays and nested matrices cleanly.

A = [1.0, 2.0, 3.0];
B = [[1.0, 2.0], [3.0, 4.0]];

Array Generators

Use built-in functions to generate arrays instantly.

X = linspace([-10.0, 10.0, 100]);

Element-wise Math

Mathematical operators and trig functions are inherently vectorized across arrays.

Y = sin(X) + cos(X);

Linear Algebra

Use the `@` operator for dot products and matrix multiplication, and `transpose()` to swap axes.

Z = A @ transpose(B);

Autograd (Neural Nets)

Use backwards propagation natively for training networks.

backward(Loss);
