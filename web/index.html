The Native Math Engine

OpenMat is a high-performance mathematical scripting language powered by a native Rust engine. It compiles directly into WebAssembly, allowing complex calculus and matrix algebra to run instantly anywhere.

🚀 What is OpenMat?

A specialized syntax tree for deep mathematical operations. It natively supports:

  • Element-wise Tensor Math across multi-dimensional arrays
  • Linear Algebra (`@` Dot Products, Matrix Transpositions)
  • Autograd (Reverse-mode backpropagation for ML)

💻 Installation

The OpenMat Native CLI Engine is currently available for macOS. The Web IDE and VS Code Extension run flawlessly on all platforms.

macOS Native Installer:

Download the official .pkg installer directly from our GitHub Releases.

Windows & Linux (Compile from Source):

$ git clone https://github.com/openmat/openmat-core.git
$ cd openmat-core/compiler
$ cargo build --release

VS Code Extension (Syntax Highlighting):

$ code --install-extension openmat-0.1.0.vsix

🌍 Mission & Vision

Our vision is to build an entirely open-source, highly parallelized ecosystem to rival legacy systems like MATLAB. By leveraging Rust and WebAssembly, we bring compute-heavy ML algorithms directly to the browser.

🛠️ Contribute

OpenMat is actively looking for contributors! Our roadmap includes:

  • WebAssembly File I/O Support (read_csv / csvwrite)
  • Pandas-style DataFrames natively in Rust
  • 3D WebGL plotting implementations
